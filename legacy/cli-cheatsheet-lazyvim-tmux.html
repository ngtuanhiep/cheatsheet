Downloader tiện cho file, recursive fetch và resume

network

Download

wget URLDownload file.
wget -O output.zip URLTên output.
wget -c URLResume.
wget -P ~/Downloads URLChọn directory output.
wget --limit-rate=2m URLGiới hạn tốc độ.

Recursive

wget -r URLRecursive download.
wget -np -r URLKhông đi lên parent.
wget -m URLMirror mode.
wget --spider URLCheck resource không download.
FF

ffmpeg

Swiss-army knife cho audio/video: convert, trim, extract, compress

media

Inspect / convert

ffmpeg -i input.mp4Inspect streams/metadata.
ffmpeg -i input.mov output.mp4Convert container/codec mặc định.
ffmpeg -i input.wav output.mp3Convert audio.
ffmpeg -i input.mp4 -vn audio.mp3Extract audio.

Trim / resize

ffmpeg -ss 00:01:00 -to 00:02:00 -i in.mp4 -c copy out.mp4Trim nhanh không re-encode.
ffmpeg -i in.mp4 -vf 'scale=1280:-2' out.mp4Resize width 1280 giữ ratio.
ffmpeg -i in.mp4 -r 30 out.mp4Set 30 FPS.

Compression

ffmpeg -i in.mp4 -c:v libx264 -crf 23 -c:a aac out.mp4H.264 CRF 23.
ffmpeg -i in.mp4 -c:v libx265 -crf 28 out.mp4HEVC nhỏ hơn, encode chậm hơn.
ffmpeg -i in.wav -b:a 192k out.mp3MP3 192 kbps.

Useful

ffmpeg -i in.mp4 -frames:v 1 cover.jpgLấy frame đầu.
ffmpeg -ss 10 -i in.mp4 -frames:v 1 shot.jpgScreenshot tại 10s.
ffmpeg -i in.mp4 -map 0:s:0 subs.srtExtract subtitle stream.

yt-dlp

Download media từ các site được hỗ trợ; kết hợp ffmpeg để merge/convert

media

Formats

yt-dlp URLDownload mặc định.
yt-dlp -F URLList formats.
yt-dlp -f 'bv*+ba/b' URLBest video + best audio.
yt-dlp -S 'res:1080' URLƯu tiên tới 1080p theo sort.

Audio / output

yt-dlp -x --audio-format mp3 URLExtract MP3.
yt-dlp -o '%(title)s.%(ext)s' URLOutput template.
yt-dlp -P ~/Downloads URLOutput path.
yt-dlp --embed-thumbnail -x --audio-format mp3 URLMP3 + thumbnail nếu hỗ trợ.

Subtitles / playlist

yt-dlp --write-subs --sub-langs 'en.*,vi.*' URLDownload subtitles.
yt-dlp --write-auto-subs URLAuto subtitles nếu có.
yt-dlp --no-playlist URLChỉ item hiện tại.
yt-dlp -o '%(playlist_index)s - %(title)s.%(ext)s' PLAYLISTTên file theo playlist index.
Chỉ tải nội dung khi bạn có quyền và tuân thủ điều khoản dịch vụ/bản quyền.
